## Границы самообучения

- Supervisor адаптирует только два порога локального детектора ям и только в заданных границах.
- Groq выдаёт диагноз и может подготовить diff, который компилируется/тестируется в staging.
- Изменения исходного торгового кода автоматически в live-файлы не применяются.
- Контрфактическая прибыль рассчитывается по сохранённым REST/stream-снимкам и не является доказательством фактической исполнимости заявки по этим ценам.
