# Hotfix v1.8.3 — исправление отображения портфеля T-Invest

## Что исправлено

- `RUB000UTSTOM` и другие валютные позиции больше не считаются акциями.
- В `/status` вложенность считается только по акциям, поэтому чистый рублёвый остаток будет показываться как свободные деньги, а не как 100% вложенности.
- Ложное расхождение `state=0 / broker=99566` по денежному остатку исчезнет.
- Настоящее расхождение по акциям выключает новые автопокупки. Защита/продажи существующих позиций продолжают работать.
- При пустом shortlist сканер пишет, какой математический фильтр отсеял кандидатов.

## Обновление

Сделайте резервную копию и распакуйте архив в каталог проекта, не удаляя `.env`, `state.json`, `data/` и `logs/`. Затем: 

```bash
cd ~/trading_bot/moex
cp tinkoff_client.py tinkoff_client.py.bak
cp trading_engine.py trading_engine.py.bak
cp telegram_bot.py telegram_bot.py.bak
cp scanner.py scanner.py.bak
# Загрузите ZIP в этот каталог, затем:
unzip -o moex_trading_bot_v1.8.3.zip
venv/bin/python -m py_compile *.py
PYTHONPATH=. venv/bin/python dry_run_test.py
```

Если в проекте есть виртуальное окружение с зависимостью `groq`, `PYTHONPATH=.` достаточно. Не копируйте тестовую заглушку Groq в рабочее окружение.

После успешной проверки остановите старый процесс через `Ctrl+C` и запустите `venv/bin/python main.py`. Сначала проверьте `/status` и `/positions`. Если обнаружено расхождение по реальным акциям, бот выключит новые автопокупки; сверяйте позиции вручную и включайте `/toggle_trading` только после устранения причины.
