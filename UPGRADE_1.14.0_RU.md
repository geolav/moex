# Обновление до v1.14.0 (скальп «как у владельца»)

## Кратко
v1.14.0 добавляет быстрый тейк «издержки+маржа» (продажа всей позиции, как
только плюс покрыл комиссию за продажу), опрос цены каждые 5-10 секунд в обоих
режимах (включая ручные покупки), детектор «локальной ямы», вызов Groq даже
при пустом shortlist и отключает правило «после убытков бумаге не доверяем».

## Обновление на VPS (без потери состояния)
```bash
cd /opt/trading_bot
systemctl stop moex-bot            # или как у вас называется сервис
# заменить .py-файлы, prompts/, .env.example, README.md на новые
cp .env .env.backup_114
# сверить .env с новым .env.example: добавить новые переменные (см. ниже)
source venv/bin/activate
python dry_run_test.py             # должно быть: 141 проверка, 0 провалов
systemctl start moex-bot
journalctl -u moex-bot -f          # смотреть старт
```

state.json / data/ (память сделок, лимиты Groq) совместимы со старыми версиями:
новые поля позиций дописываются автоматически при первом проходе миграции.

## Новые переменные .env (все имеют дефолты - можно ничего не добавлять)

| Переменная | Дефолт | Что делает |
| --- | --- | --- |
| `SCALP_QUICK_TP` | `True` | Быстрый тейк: продавать ВСЮ позицию, как только плюс покрыл круговые издержки. `False` возвращает лестницу 1R/2R. |
| `SCALP_QUICK_TP_MARGIN_PCT` | `0.05` | Запас сверху издержек, п.п. (цель = издержки + это значение). |
| `SCALP_EXIT_POLL_SEC` | `10` (было 30) | Опрос цены открытых позиций, сек (5-120), теперь в обоих режимах. |
| `SCALP_DIP_ENABLED` | `True` | Второй триггер входа: остановившаяся «локальная яма». |
| `SCALP_DIP_WINDOW_SEC` | `240` | Окно поиска провала, сек. |
| `SCALP_DIP_MIN_DROP_PCT` | `0.20` | Минимальная глубина провала от максимума окна, %. |
| `SCALP_DIP_STABILIZE_SEC` | `20` | Сколько секунд без нового минимума = падение остановилось. |
| `SCALP_DIP_MIN_IMBALANCE` | `1.15` | Перевес покупателей в стакане у дна. |
| `MEMORY_LOSS_STREAK_GUARD` | `False` | `True` возвращает пакет «недоверие после убытков» (пауза после 3 убытков, повышенный порог после 2, «плохие часы», глобальная пауза скальпа). В скальпе не работает даже при `true`. |
| `SCAN_EMPTY_SHORTLIST_FALLBACK` | `True` | Пустой shortlist -> Groq всё равно получает до 3 лучших безопасных бумаг. |

## Изменённые дефолты
- `SCALP_EXIT_POLL_SEC`: 30 → **10**.
- `MEMORY_LOSS_STREAK_GUARD`: правил недоверия больше нет по умолчанию.
- В скальпе позиция теперь чаще всего закрывается по быстрому тейку
  (≈ +0.15-0.25%), а не по 1R - это осознанное поведение по запросу владельца.

## Что проверить после запуска
1. `/scalp on` - в описании режима должны быть «БЫСТРЫЙ ТЕЙК ... продаю ВСЮ
   позицию», «локальная яма», «опрос цены каждые 10 сек» и «правило недоверия
   ВЫКЛЮЧЕНО».
2. `/buy ТИКЕР ШТ` в торговое время - ответ должен обещать быстрый тейк и
   частый опрос; через 10-20 секунд `/positions` должен показывать свежий P&L.
3. В логе при пустом shortlist: «Сканер: строгий shortlist пуст - включаю
   fallback: ИИ оценивает ... бумаг» и затем «Scalp AI batch: отправлено ...» -
   Groq теперь вызывается.
4. Если какая-то из новых проверок не нужна - всё выключается из .env без
   правки кода.
