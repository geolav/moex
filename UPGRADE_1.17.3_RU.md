# UPGRADE 1.17.3

## Обновление

```bash
cd ~/trading_bot/moex
# распаковать архив поверх текущей папки (или скопировать .py файлы)
venv/bin/pip install -r requirements.txt   # зависимостей не добавилось
systemctl restart trading_bot              # или перезапустить main.py вручную
```

Версия в шапке лога должна стать `MOEX Trading Bot v1.17.3`.

## Проверьте .env

- Если в `.env` задан `SCALP_MIN_REWARD_COST_MULTIPLE=4.0` — **удалите строку
  или поставьте 1.10**. Со старой четвёркой фильтр издержек по-прежнему будет
  отменять входы (смысл переменной изменился: теперь она умножается на
  потенциал отскока, а не на стоп).
- Быстрый трек включён по умолчанию. Чтобы вернуть старое поведение
  («покупаем только после ответа ИИ»), добавьте `SCALP_FASTTRACK_ENABLED=false`.

## Как убедиться, что покупки пошли

1. В логе после строк `Микрояма … сигнал распознан, прогоняю фильтры входа`
   ищите:
   - `XXX: БЫСТРЫЙ ТРЕК ямы: сильная яма: score NN/100, потенциал … - вхожу
     без ожидания Groq batch` → сразу заявка на покупку;
   - `XXX: локальные фильтры пройдены (dip_reversal); кандидат добавлен в
     очередь Groq batch` → кандидат ждёт ИИ (средние сигналы);
   - `Scalp AI batch: отправлено N кандидата(ов), валидных решений M` → ИИ
     реально отвечает.
2. В Telegram сообщение приходит **только при фактической покупке** (как вы
   и просили): тикер, сколько, по какой цене и краткая причина. Тишина в чате
   при активных логах — норма: это сигналы без покупок.
3. `/positions` показывает изменение цены **с учётом полных издержек круга**,
   а скальп-охрана продаёт позицию, как только брутто-рост покрывает издержки
   (`Скальп-мониторинг … ПОРОГ ДОСТИГНУТ`).
