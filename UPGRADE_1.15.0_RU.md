# UPGRADE v1.15.0 — как обновиться с v1.14.0

Обновление полностью обратно совместимо: новые поля state добавляются
сами, ничего в .env менять не обязательно.

## Шаги

```bash
cd /opt/moex_trading_bot        # каталог установки (пример)
systemctl stop trading_bot      # имя вашего сервиса (trading_bot.service)
# распаковать архив v1.15.0 поверх, заменив .py-файлы и docs
# .env НЕ трогаем; сравнить с .env.example можно так:
#   diff .env .env.example
python3 -m py_compile *.py      # проверка синтаксиса
systemctl start trading_bot
journalctl -u trading_bot -f    # в логе: "MOEX Trading Bot v1.15.0 стартует"
```

## Что изменилось в настройках

| Параметр | Было | Стало | Обязательно? |
|---|---|---|---|
| `SCAN_REPORT_TOP` | 6 | 4 | нет, можно оставить как было (диапазон 3-10) |
| остальные | — | без изменений | — |

## Что появится в поведении

1. **Тишина между сканами.** Сканер перестаёт писать отчёты каждые
   10 минут. Если захочется глянуть рынок — `/scan` в Telegram: полный
   отчёт с топ-4 и графиками, как раньше.
2. **Сообщения только о покупках.** При автопокупке придёт короткая
   сводка (тикер, лоты/штуки, цена, сетап + уверенность ИИ) и подробное
   сообщение движка о сделке.
3. **/positions и /status показывают вердикт продажи**: «продавать можно»
   / «комиссия покрыта, бот ждёт порог» / «продавать рано» — с порогом
   бота и ценой, при которой продажа становится плюсом после комиссии.
4. **Одинаковые дневные цифры.** /status («📈 Результат дня: …»),
   /memory («📊 Сегодня реализовано (по счёту)…») и сообщения движка
   показывают ОДНО число — то же, по которому работает дневной стоп.
5. **Счётчик сделок честный.** /stats показывает «Сделок исполнено: N»
   по журналу сделок за сегодня (по МСК). История сделок дня сохраняется
   в state.json (`trade_journal`, до 200 событий, чистится в полночь).

## Проверка после обновления

- `/status` — появилась строка «📈 Результат дня: …»;
- `/positions` (если есть позиции) — в каждой строке вердикт продажи;
- `/stats` — «Сделок исполнено: N» вместо почти всегда «0»;
- `/scan` — полный отчёт с «топ 4 кандидатов»;
- подождать скан — убедиться, что без покупки сообщений нет.
