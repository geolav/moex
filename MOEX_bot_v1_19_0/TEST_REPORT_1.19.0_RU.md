# Проверка v1.19.0 — MOEX Market AI

## Автоматические тесты

Команды, выполненные в среде сборки:

```bash
python -m unittest discover -q
pytest -q --ignore=dry_run_test.py
python -m compileall -q market_ai
```

Результат:

- `unittest discover`: **102 теста, 0 ошибок**.
- `pytest --ignore=dry_run_test.py`: **102 passed**.
- `market_ai` проходит компиляцию Python.
- Legacy `dry_run_test.py` в этой среде не включён в pytest-прогон: при полной коллекции pytest ему требуется пакет `groq`, которого нет в среде сборки. Сам торговый код и optional ML-пакет не устанавливают Groq автоматически.

## End-to-end smoke test

Полный pipeline был запущен на искусственно сгенерированных OHLCV-свечах (не на рыночной истории):

- 3 120 свечей, 1 условный тикер, 8 искусственных дат;
- последовательности длиной 30 минут, stride 12;
- обучение Logistic Regression, HistGradientBoosting, MLP и GRU;
- MLP/GRU обучались 2 эпохи с validation loss и early stopping;
- созданы отчёты, scaler, sklearn-артефакты и веса обеих нейросетей;
- `market_ai.predict` загрузил GRU checkpoint и сформировал семигоризонтный прогноз.

Этот прогон подтверждает техническую работоспособность обучения и inference. **Его accuracy и выбор лучшей модели не являются показателями качества на MOEX**, так как исходные свечи синтетические.

## Что ещё требуется перед оценкой на рынке

Для рыночного отчёта нужны реальные минутные свечи за несколько месяцев и копия `data/supervisor.sqlite3`. В архив намеренно не включены пользовательская база, токены, свечи и обученные на счёте веса. После запуска на реальных данных качество следует оценивать по отложенным торговым датам, UP precision, числу независимых сигналов и net-return после фактических издержек.
