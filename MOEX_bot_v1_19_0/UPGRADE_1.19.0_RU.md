# Обновление до v1.19.0

1. Остановите бота штатно и сделайте резервную копию всей папки, `.env`, `state.json`, `data/` и SQLite.
2. Распакуйте архив v1.19.0 в отдельную папку. Перенесите туда свой `.env` и пользовательские данные. Не заменяйте старую папку `data/` пустой папкой из архива.
3. Запустите обычный бот как раньше. Для основного торгового процесса новые зависимости не нужны.
4. ML-эксперименты запускайте отдельно, предпочтительно на локальном компьютере/машине с памятью от 4 ГБ, а не внутри systemd-процесса на VPS с 1 ГБ ОЗУ.
5. Установите optional зависимости: `python3 -m pip install -r requirements_market_ai.txt`.
6. Скачайте 1m историю через `python3 -m market_ai.fetch_tbank ...` с переменной `TINKOFF_TOKEN` и обучите модель командой из `market_ai/README_RU.md`.
7. Чтобы учесть события Supervisor, скопируйте `data/supervisor.sqlite3` в ML-рабочую папку и передайте путь через `--sqlite`. Токены не нужны для чтения SQLite.
8. Проверьте `REPORT_RU.md`, `metrics.csv`, особенно test macro-F1, UP precision, число сигналов и net-return после издержек.
9. Прогнозы через `market_ai.predict` являются исследовательскими. Автоторговля не подключена и не изменена.

Архив не содержит `.env`, токенов, реальной базы SQLite, истории свечей или обученных на пользовательском счёте весов.
