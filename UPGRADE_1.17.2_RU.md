# UPGRADE 1.17.1 → 1.17.2

## Что изменилось
Детектор локальных микродн больше не блокируется молчащим стаканом:
- стакан по стриму может не приходить (сервер отклоняет подписку) — теперь
  это видно в логе, а bid/ask освежается по REST;
- без стакана локальное дно ищется по структуре цены (price-only, вкл. по
  умолчанию);
- спред при отсутствии стакана берётся из REST/ISS/консервативной оценки,
  а не бракует сигнал и вход.

Новых обязательных шагов нет. Обновление — распаковка файлов поверх рабочей
папки (или git pull), рестарт процесса.

## Шаги

```bash
cd /root/trading_bot/moex
# 1) остановить бота (systemd или процесс venv/bin/python main.py)
# 2) скопировать файлы новой версии поверх (zip распаковать с заменой)
# 3) (необязательно) добавить в .env новые настройки:
#    SCALP_MICRO_PRICE_ONLY=true        # поиск микродн без стакана
#    SCALP_BOOK_REST_REFRESH_SEC=30     # REST-обновление стакана, сек
#    SCALP_REST_BOOK_MAX_AGE_SEC=45     # срок годности REST-стакана
#    SCALP_DEFAULT_SPREAD_PCT=0.05      # консервативный спред-фолбэк, %
# 4) запустить бота
```

state.json, data/ и логи не трогаются — обновление только кода.

## Что проверить после старта (первые 10–15 минут)

1. `Scalp stream: подписка last_price подтверждена для N бумаг` — и, если
   стакан по-прежнему не приходит, **WARNING `сервер ОТКЛОНИЛ подписку
   orderbook …`** с названием статуса. Это ответ на вопрос «почему стакана
   не было» — пришлите эту строку, если захотите разбираться с лимитами
   тарифа.
2. `Scalp stream ЗДОРОВ: цена свежая 15/15; стакан (стрим) 0/15; стакан по
   REST: …; буферы тиков [GAZP:120, …]` — цена и стакан теперь считаются
   раздельно; буферы тиков должны быть непустыми.
3. Строки `Микродно TICKER: …` теперь показывают реальные окна
   (12 20 35 60 120 240) и реальную причину отказа (структура дна/издержки),
   а не «стакан устарел».
4. При подтверждённом дне: `Микрояма TICKER: масштаб …; кандидат передан в
   ограниченную AI-очередь` — дальше как обычно: Groq-пакет, лимиты, покупка.

## Откаты
Если что-то пойдёт не так: вернуть папку из бэкапа v1.17.1 (или закомментировать
новые переменные в .env — код работает и без них, это значения по умолчанию).
`SCALP_MICRO_PRICE_ONLY=false` возвращает прежнее жёсткое поведение «нет
свежего стакана — сигнала нет».
